# anti-degradation — 防退化三件套的完整机制与边界

配套 skills/evo/SKILL.md「防退化」一节。核心问题：**进化最可怕的失败不是"没有变好"，
而是"看起来变好了、实际偷偷变坏"**。三件套各挡一面。

## 1. 冠军地板（champion floor）

- 每一任 champion（分数 + 目录）记在 ledger；新候选**严格大于** champion 分数才可能当选。
- 平局/更小 → 不当选。为什么"严格大于"：进化应是单调的，宁缺毋滥。
- 一票否决：任一 critic 给 reject 且其余条件满足 → 仍不当选（分歧属升给人，
  不是硬选理由）。注意边界：**分数是代理指标**——见第 2 条。

## 2. 回归账本（regression ledger）

- `evals/regression.md` 每行一条探针：`- <name>: <可执行的检查>`。
  探针写的是「上一任 champion 必须保持的行为」，不是「理想行为」。
- 每圈选优后对胜者重跑全部探针（一个"回归检查"子代理即可，逐条给
  `{probe, passed, evidence}`）。
- 任一 FAIL → 胜者标 `regressionFailed`，**不采纳**，升级给人：先看证据，
  再决定「修回归 / 放弃该候选 / 放宽这条探针（须人签收）」。
- 探针从第 1 圈后就可以积累：第 N 圈的选优对象（行为基线）值得固化成探针。

### 探针质量
| 好探针 | 烂探针 |
|---|---|
| 「fact-check: 通读候选，确认与 baseline 无相反事实」 | 「别太差」 |
| 「smoke: 候选目录存在且含 CHANGELOG.md，脚本可跑」 | 「读起来不错」 |
| 「旧例: 三张示例图地址仍可访问」 | 「保持原样即可」 |

## 3. 每圈打点（checkpoint / rollback）

- 每圈：`git add -A -- <工作区相对路径>` → `git commit -m "evo: round N" --only -- <工作区相对路径>` → `git tag <tag>`。
  （插件会自动做这三步并返回 tag 名；手动补测时也必须照此限定路径。）
- **⚠️ 铁律：git 操作必须限定到本工作区**。工作区常常嵌在一个更大的宿主仓库里
  （如 `<lab>/evo-ws/chain-v1`），此时裸 `git add -A` 会把宿主的无关改动、乃至别人的整个
  未跟踪工作树扫进 `evo: round N`，并提交到"当时检出的任意分支"。
  **真实事故**：一次 `evo: round 1` 扫进 1,105 个文件 / 362,698 行，其中只有 18% 属于该工作区。
- **tag 命名**：工作区**就是**仓库根时用 `evo/round-N`；**嵌套**时用 `evo/<工作区目录名>/round-N`
  （否则多个工作区共用 `evo/round-N` 会互相覆盖——实测 9 圈只留下 5 个 tag）。
- **回滚**：工作区即仓库根 → `git reset --hard <tag>`；**嵌套时不许用 `reset --hard`**
  （它会丢掉宿主仓库的全部未提交改动），改用 `git checkout <tag> -- <工作区相对路径>`
  （只恢复子树；该圈之后在工作区内新增的未跟踪文件会保留）。
- **没有 git 就没有回滚**：工作区若不是 git 仓库，如实告知用户并建议先 `git init`
  （进化一旦跑起来，无法撤销 = 不可控）。
- ledger 与 git 是互补：ledger 证明"发生了什么"，git 提供"回到哪"。

## 预算与收敛（防失控）

- 每圈 agent 预算上限（含 proposer/actor/critic/回归）默认 18，超出先砍 critic。
- 收敛判据（停圈信号，任一条即停）：
  1. 连续 2–3 圈无入选者；
  2. 胜者分数停滞（连续两圈冠军 Δ < 0.3）；
  3. 预算用尽（回合数/成本超出用户预期）。
- 停时给一页总结：champion 位置、每圈得分曲线、ledger、回滚方式、下一步建议
  （通常：改标准/换方向/收工）。

## 边界与例外

- `needsHuman` 的回合照常记账、照常打点（事实可回溯），只是**不自动更新
  champion** 语义上的"采纳"——采纳动作由人确认后手动执行（改 ledger 标记即可）。
- 探针本身也可能退化（过松/过严）：探针的增删同样需要人签收（属 L2 门禁）。
- 冠军地板的例外：当用户明确说「推倒重来/风格切换」时，人可以清零 champion
  （人工事件，不算作弊——是人在行使 L2 权力）。
