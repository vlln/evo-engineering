# 为什么我们每个人都应该拥抱 AI 时代的自我进化

上个月我做了个小实验：写了一个不到两千行的五子棋小智能体，让它自己跟自己下，输了就自己调下法参数。头两个晚上它开局就被杀穿，我随手下的开局它都挡不住。第三天早上我起来看了一眼，它已经会堵我的活三了——而我一行代码都没改，只是给它留了个每晚自动跑三千局对弈的任务。这就是自我进化（Self-Improvement）最朴素的样子，它正在从科幻小说走进现实。

说白了，自我进化就是一句话：系统靠自己的运作改进自己。听着抽象，可我们身边到处是例子——机器学习模型靠训练数据越练越强，本质上就是自我进化。

但自我进化从机器跑到人身上，意义就不一样了。它不只是提高效率，还能帮我们发现新的可能性。想象一下，如果你的工作流程能自己优化，省下的时间和资源可以投到真正创造性的地方去——这可比省几小时电费值钱得多。

其实，面对这个趋势，该做的反而简单：保持开放，持续学新东西。但我这儿想留一句可能会被反驳的判断：「会自我改进」不等于「在进化」。一个人如果只反复做自己已经会的事，那被进化的只是工具，不是他自己。

至于机器自我改进算不算进化，我的判断是：算，但当且仅当改进发生在它没见过的任务上——套着老办法把旧任务刷到 99%，那只是拟合。这句话我欢迎反驳。
